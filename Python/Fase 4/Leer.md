En esta etapa los ejercicios se guardar en carpetas, por la Modularización.

> ***Importante:** Para estos ejercicios deberás crear varios archivos `.py` en la misma carpeta. No queremos todo el código en un solo archivo.*

### Un consejo para esta etapa

A partir de ahora intentá crear una carpeta para cada ejercicio cuando corresponda. Acostumbrarte desde el principio a trabajar con varios archivos y una estructura organizada te va a ahorrar muchos problemas cuando empecemos con Flask y FastAPI, donde un proyecto real puede tener decenas de módulos y cientos de archivos.
