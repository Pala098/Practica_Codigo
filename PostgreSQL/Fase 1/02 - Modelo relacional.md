1. Que función cumple una PK?

>La función de una PK es identificar de manera única cada una de las tablas dentro de una base de datos, o entidades.

2. Que función cumple una FK?

> La función de una FK es de relacionar las diferentes tablas entre si. Este valor casi siempre es una copia de una PK de la tabla con la cual se quiere relacionar.

3. Por que una base de datos relacional utiliza varias tablas relacionadas en lugar de guardar todo en una sola tabla gigante? 

>Porque esto simplifica las relaciones, tener todo en una misma tabla seria caótico y tosco a la hora de filtrar información, en cambio teniendo diferentes tablas se puede filtrar y visualizar de una forma mas fácil y sencilla de entender.
