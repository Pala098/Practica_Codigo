## Consulta A
```sql
select nombre from clientes where ciudad in ('La Plata','Córdoba');
```
Preguntas
1. ¿Cuántas filas devolverá?
	Devolverá 3 filas.
2. ¿Qué nombres aparecerán?
	Aparecerán Ana, Juan y Lucia.
3. Explica el porqué.
	Porque en la consulta estamos aplicando 'in' y le damos los valores de la plata y cordoba, lo cual devolvera los registros que contengan estos.

## Consulta B
```sql
select producto from productos where precio in (25,90,1200);
```
Preguntas
1. ¿Qué productos aparecerán?
	Aparecerán Mouse, auriculares y notebook.
2. ¿Por qué no aparece "Monitor"?
	Porque no cumple con el criterio de 'in', dentro de los valores.

## Consulta C
```sql
select ciudad from clientes where nombre in ('Ana','Pedro');
```
Preguntas
1. ¿Qué ciudades aparecerán?
	Aparecerán La Plata y Mendoza.
2. ¿Cuántas filas devolverá?
	Devolverá dos filas.
3. ¿Puede haber ciudades repetidas? ¿Por qué?
	Si, porque el criterio solo filtra los valores que contengan lo que pasamos en el criterio IN, no se aplica ningún filtro que saque valores repetidos.

## Mini Sprint: TechStore
Imagina que hoy es tu segundo día de trabajo.
Tu jefe te dejó cinco requerimientos para resolver antes del mediodía.
Cada uno es independiente.
### Ticket #1
El área de ventas necesita un listado con el **nombre** y la **ciudad** de todos los clientes que viven en **Córdoba** o **Mendoza**.

```sql
select nombre, ciudad 
from clientes
where ciudad in ('Córdoba','Mendoza');
```

### Ticket #2
El área de compras quiere revisar los productos **Mouse**, **Teclado** y **Auriculares**.
Solo necesita ver:
- producto
- precio
El listado debe estar ordenado **del más barato al más caro**.

```sql
select producto,precio
from productos
where producto in ('Mouse','Teclado','Auriculares')
order by precio asc;
```

### Ticket #3
Marketing necesita saber **en qué ciudades** tiene clientes.
No quiere que una ciudad aparezca más de una vez.

```sql
select distinct ciudad
from clientes;
```

### Ticket #4
El gerente quiere conocer los **dos productos más caros** de la tienda.
Solo necesita:
- producto
- precio

```sql
select producto, precio
from productos
order by precio desc
limit 2;
```

### Ticket #5
Necesitamos encontrar todos los productos cuyo nombre contiene la cadena:

```
te
```

Mostrar únicamente el nombre del producto.

```sql
select producto
from productos
where producto like '%te%';
```
